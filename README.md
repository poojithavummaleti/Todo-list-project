# To-Do List Application

A simple desktop To-Do List application developed using C#, WPF and .NET.

## Technologies Used

* C#
* WPF
* .NET
* XAML

## Features

* Add new tasks
* Complete tasks
* Delete tasks
* Basic input validation
* Display tasks using a ListBox

## Concepts Used

* C# Classes
* ObservableCollection
* Event Handling
* WPF Controls
* XAML
* Basic Input Validation

## How to Run

1. Clone or download the repository.
2. Open the solution/project in Visual Studio.
3. Build the project.
4. Run the application using F5.

## Project Purpose

This project was created to practice C# programming and WPF desktop application development.
